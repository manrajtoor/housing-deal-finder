# housing-deal-finder

Finds under-priced homes: NYC 2+ bedroom apartments for sale, and waterfront
houses around Grand Traverse / Leelanau and Petoskey / Charlevoix, Michigan.
Work in progress.

Michigan water types come partly from map data: © OpenStreetMap contributors,
ODbL 1.0 (https://www.openstreetmap.org/copyright). See tools/geo/README.md.
